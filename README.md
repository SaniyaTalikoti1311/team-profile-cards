# Team Profile Cards

A React app that showcases team members with profile cards — name, age, role, bio, availability status, and social links.

## 🔗 Live Demo
[https://team-profile-cards.vercel.app](https://team-profile-cards.vercel.app)

## Getting started

```bash
npm install
npm run dev
```

## Project structure

```
src/
  App.jsx              # renders the list of ProfileCard components
  App.css              # page-level layout styles
  main.jsx             # React entry point
  Components/
    TeamCard.jsx        # reusable card component
    TeamCard.css        # card-specific styles
  assets/               # team photos
```
